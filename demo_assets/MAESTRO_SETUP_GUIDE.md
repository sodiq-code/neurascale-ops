# Maestro Setup Guide — NeuroScale Ops

**When your UiPath AgentHack Labs access arrives (~3 business days from June 8, 2026), follow this guide step-by-step.**

---

## Prerequisites

- [ ] UiPath Automation Cloud account with Maestro enabled
- [ ] Python 3.11+ installed
- [ ] Groq API key (get free at console.groq.com)
- [ ] Git repo cloned: `git clone https://github.com/sodiq-code/neurascale-ops`
- [ ] `.env` file configured (see below)

---

## Step 1 — Environment Setup

```bash
cd neurascale-ops
pip install -r requirements.txt

# Create .env file
cat > .env << EOF
GROQ_API_KEY=your_groq_key_here
DEMO_MODE=true
UIPATH_TENANT_URL=https://cloud.uipath.com/your-org/your-tenant
UIPATH_CLIENT_ID=your_client_id
UIPATH_CLIENT_SECRET=your_client_secret
EOF
```

### Verify pipeline works before touching UiPath:
```bash
python main.py
# Expected: 5 incidents processed, all RESOLVED
python -m pytest tests/ -v
# Expected: 17 passed
```

---

## Step 2 — Import Maestro Case Definition

1. **Login** to UiPath Automation Cloud
2. Navigate to **Maestro** → **Cases** → **New Case**
3. Click **Import from JSON**
4. Upload: `uipath/maestro_case/case_definition.json`
5. Name it: `NeuroScale Ops — K8s Incident Response`

### Verify the import:
- Should see 7 stages in the stage graph
- Each stage should show its SLA, type, and connections
- Stage 4 (Human Approval) should show 15-min SLA with escalation rule

---

## Step 3 — Deploy Coded Agents

The Python agents become **UiPath Coded Agents** connected to Maestro.

### 3a. Package the agents

```bash
# Install UiPath CLI (once platform access is confirmed)
pip install uipath

# Login
uipath auth login

# Package each agent
uipath agent package --name DetectorAgent --source agents/detector/detector.py
uipath agent package --name TriageAgent --source agents/triage/triage_agent.py  
uipath agent package --name CostImpactAgent --source agents/cost_impact/cost_agent.py
uipath agent package --name RemediationAgent --source agents/remediation/remediation_agent.py
```

### 3b. Publish to Orchestrator

```bash
uipath agent publish DetectorAgent
uipath agent publish TriageAgent
uipath agent publish CostImpactAgent
uipath agent publish RemediationAgent
```

### 3c. Link agents to Maestro stages

In the Maestro Case editor:
- Stage 1 (Detection) → Assign: `DetectorAgent`
- Stage 2 (Triage) → Assign: `TriageAgent` + Set env var: `GROQ_API_KEY`
- Stage 3 (Cost Impact) → Assign: `CostImpactAgent`
- Stage 5 (Remediation) → Assign: `RemediationAgent`

## Step 4 — Configure API Workflows

### Prometheus Webhook Receiver

1. Navigate to **Integration Service** → **API Workflows**
2. Create new workflow: `PrometheusWebhook`
3. Trigger: HTTP POST endpoint
4. Body mapping:
   ```json
   {
     "alert_name": "$.alerts[0].labels.alertname",
     "severity": "$.alerts[0].labels.severity",
     "namespace": "$.alerts[0].labels.namespace",
     "pod": "$.alerts[0].labels.pod"
   }
   ```
5. Action: Start Maestro Case `NeuroScale Ops — K8s Incident Response`

### OpenCost Query Workflow

1. Create workflow: `OpenCostQuery`
2. HTTP GET to: `http://<opencost-service>:9003/allocation/compute`
3. Parameters: `window=30d&namespace={namespace}`
4. Parse response → return `monthly_cost`, `budget_limit`

## Step 5 — Create UiPath Apps Forms

Three forms to build. Use **UiPath Apps** → **New App**.

### Form 1: Triage Approval (`triage_approval_form`)

Fields:
- Alert ID (read-only text)
- Incident Type (read-only badge: OOMKill / CrashLoop / etc.)
- AI Root Cause (read-only text)
- Confidence Level (badge: HIGH=green, MEDIUM=yellow, LOW=red)
- AI Reasoning (read-only textarea, max 500 chars)
- Recommended Action (read-only text)
- Current Monthly Cost (read-only: `$XXX/mo`)
- Remediation Cost Delta (read-only: `$+15/mo` or `$-120/mo`)
- **APPROVE button** (green, primary) → triggers `on_approve` in Maestro
- **REJECT button** (red, secondary) → triggers `on_reject` in Maestro

SLA reminder: Display countdown from 15-minute SLA. Auto-escalate if timeout.

### Form 2: Remediation Signoff (`signoff_form`)

Fields:
- Alert ID (read-only)
- Action Taken (read-only)
- Execution Status (badge: SUCCESS / FAILED)
- Duration (read-only: `0.002s`)
- Command Executed (read-only code block)
- **CONFIRM RESOLVED** button (green)
- **ESCALATE** button (orange)

### Form 3: Post-Mortem Review (`postmortem_review_form`)

Fields:
- Incident summary table (read-only)
- PDF download link (generated by Document Understanding)
- **CLOSE CASE** button

## Step 6 — Set Up Agent Builder (Slack Notifications)

1. Navigate to **Agent Builder** → **New Agent**
2. Name: `IncidentNotifier`
3. Trigger: Maestro webhook on stage completion
4. Actions:
   - **Send Slack Message** (via Integration Service → Slack connector)
   - Message template:
     ```
     🚨 *[{severity}] {alert_type} — {namespace}*
     Root Cause: {root_cause} (Confidence: {confidence})
     Action: {action} | Cost Delta: {cost_delta}
     Maestro Case: {case_url}
     ```
5. Channels:
   - `#incidents` — all alerts
   - `#sre-oncall` — CRITICAL only

---

## Step 7 — Configure Document Understanding

1. Navigate to **Document Understanding** → **Projects**
2. Create project: `IncidentPostMortem`
3. Template: Upload `uipath/apps/postmortem_template.json`
4. Fields to extract:
   - incident_id, timestamp, root_cause, action_taken
   - cost_delta, resolution_time, approver, notes
5. Output: PDF generation enabled
6. Connect to Maestro Stage 7

## Step 8 — End-to-End Test

### Trigger a demo run via webhook:

```bash
# Send test OOMKill alert to the Prometheus webhook endpoint
curl -X POST https://cloud.uipath.com/your-org/your-tenant/api/webhooks/prometheus \
  -H "Content-Type: application/json" \
  -d '{
    "alerts": [{
      "labels": {
        "alertname": "OOMKill",
        "severity": "critical",
        "namespace": "production",
        "pod": "ml-inference-pod-7d9f8b"
      },
      "annotations": {
        "message": "Container OOMKilled. Restart count: 3"
      }
    }]
  }'
```

### Expected flow:
1. Maestro Case created → Stage 1 starts (< 1 min)
2. Stage 2 Groq triage completes → structured JSON (< 2 min)
3. Stage 3 cost impact calculated (< 1 min)
4. Stage 4 UiPath Apps form appears → SRE approves
5. Stage 5 remediation executes (< 5 min)
6. Stage 5b signoff form → confirm resolved
7. Stage 7 post-mortem PDF generated

### Check Maestro audit trail:
- Navigate to **Maestro** → **Cases** → select the just-completed case
- Verify all 7 stages show completion timestamps and outputs
- Download the PDF post-mortem from Stage 7

## Troubleshooting

| Issue | Fix |
|---|---|
| `GROQ_API_KEY` not found | Ensure `.env` is in project root, `python-dotenv` installed |
| `kubectl command not found` | Set `DEMO_MODE=true` in `.env` |
| Maestro import fails | Validate JSON: `python -c "import json; json.load(open('uipath/maestro_case/case_definition.json'))"` |
| Agent package fails | Confirm UiPath CLI version ≥ 2.0 |
| Slack not receiving | Check Integration Service Slack connection token |
